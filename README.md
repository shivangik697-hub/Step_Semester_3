# Step_Semester_3 — Session 4: Functions and Arrays

This branch contains the assignment problems for Session 4 organized according to the repository standards.

## Package Structure
```
src/
└── main/
    └── java/
        └── functions_and_arrays/
            ├── class_problems/
            └── assigment_problems/
                ├── FindMinInRotatedSortedArray.java
                ├── MaximumSubarray.java
                ├── ProductExceptSelf.java
                ├── SubarraySumEqualsK.java
                └── ThreeSum.java
```

## Problems
1. **Find Minimum in Rotated Sorted Array** (`FindMinInRotatedSortedArray.java`)
2. **Maximum Subarray** (`MaximumSubarray.java`)
3. **Product of Array Except Self** (`ProductExceptSelf.java`)
4. **Subarray Sum Equals K** (`SubarraySumEqualsK.java`)
5. **3Sum** (`ThreeSum.java`)

## Language
Java

## How to Compile and Run
Compile all problems:
```bash
javac src/main/java/functions_and_arrays/assigment_problems/*.java
```

Run a specific problem (e.g. ThreeSum):
```bash
java -cp src/main/java functions_and_arrays.assigment_problems.ThreeSum
```
